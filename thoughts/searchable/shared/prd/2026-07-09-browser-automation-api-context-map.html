G4 DRIFT BC1 C1 URIValidation: uri.zig validate returns raw input verbatim; uri_test.zig asserts canonicalization Test expectations don't match implementation. Either tests are aspirational or validate is incomplete. Align: implement canonicalization in validate, or fix test expectations to match current behavior.
G5 BLOCKS BC4 S4 Platform→DOM: current path is JS→native only (zbHost). Automation requires native→JS eval. No mechanism to send commands to the page. Core automation path doesn't exist. G8 BLOCKS BC6 C16 ErrorTaxonomy: AutomationError enum doesn't exist. Only IpcError{UnknownCommand,BadArgs} today. No typed automation errors. All failures would collapse to generic errors. Define AutomationError with 12 variants (element_not_found through cancelled), map to -32001..-32012.
G9 BLOCKS BC11 S15 Components→Sink: TelemetrySink doesn't exist. No span/event infrastructure. No observability for automation commands. Investigation requires printf debugging. Implement TelemetrySink vtable, in-memory test sink, root automation.command spans, child spans.
G10 RISK BC12 C37 NetworkCapability: Linux/macOS NetworkInterceptor stubs are tracked security debt. Silent throttling (429s on XHR, WebSocket soft-bans) invisible on 2/3 platforms. Accounts burn invisibly. Log stubs as tracked debt. Revisit trigger: any account burned by undetected rate limiting.
G11 RISK BC8 C24 UDSOnly: AF_UNIX on Windows in Zig std.net unvalidated. ADR-1 contingency: TCP + bearer token. If AF_UNIX fails on Windows, transport design needs revision. Spike: test AF_UNIX socket creation/connection on Windows 10 1803+ with Zig 0.16. Pre-Phase 2.

Minimize DOM surface touched. Prefer reading over writing. Clean observers synchronously. Align with rAF cadence. Revisit trigger: any platform deploying timing-based or prototype-chain detection.
