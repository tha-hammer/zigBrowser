# Zig Browser v1 — Detailed TDD Implementation Plan

## Overview

This is the **executable, code-writing plan** for v1 of the Zig browser: a layout-first,
**no-JavaScript** static-HTML rendering engine that fetches a real HTTPS URL and renders a
readable, styled, scrollable, clickable page in a native window.

It is the detailed companion to the high-level `Plans/TDD_IMPLEMENTATION_PLAN.md`. That doc
explains *what* and *why* at the milestone level; **this doc gives the implementer the exact
Red → Green → Refactor cycles to write the code against.** Every behavior below is phrased
Given/When/Then, written failing first, then made to pass minimally, then refactored.

**Scope of this plan:** v1 Phases 0–8 **plus** the engine-agnostic JavaScript *seams* the
strategy doc requires v1 to reserve — those seams are first-class, tested behaviors here
(teardown ordering, wrapper-cache slot, microtask-pump call site, same-origin keying), even
though no engine runs in v1. Filling those seams with a real engine (the spikes, v2+) is
**out of scope** for this plan and lives in `JS_ENGINE_STRATEGY.md`.

**Core principle (non-negotiable):** No production code without a failing test that demands
it. No skipping Red.

### Constraints carried from the design docs
- **Arena-per-page** — no document-scoped data may escape the page arena.
- **Engine-agnostic seam** — no symbol, type, or comment may name a specific JS engine.
- **host-owns-handles readiness** — every DOM node reserves a (null in v1) wrapper-cache slot; JS will never hold raw DOM pointers.
- **Ordered navigation teardown** — `severHandles → drainFinalizers → arena.deinit → tear down isolate`. No finalizer may run after `arena.deinit()`.
- **Same-origin from first execution** — origin = scheme+host+port; storage/cookies origin-keyed before any script can exist.

## Desired End State

The v1 success gate (from the high-level plan) — verified through tests:
1. Fetches `https://` URLs with real certificate validation. *(fetch-bad-cert, fetch-success)*
2. Correct block + inline box tree for a real document. *(layout-block-geometry, layout-inline-wrap)*
3. Text shaped and rasterized (Latin first; UTF-8 throughout). *(paint-snapshot)*
4. Scroll works; clicking a link navigates and frees the previous arena. *(scroll, link-navigate, arena-free-on-navigate)*
5. Passes a curated WPT subset (parsing + CSS2.1 cascade + box model). *(tree/cascade/layout behaviors over WPT fixtures)*
6. Renders ≥90% of a fixed 50-page corpus acceptably. *(paint-snapshot over the corpus = the gate)*

### What We're NOT Doing (v1 hard NOs)
JS execution, flexbox/grid, transforms/animations, GPU compositing, multi-process sandbox
(architecture stays process-portable but ships single-process), tabs, history DB,
incremental/dirty-flag layout, web fonts (`@font-face`). Filling the JS seams with a real
engine, the engine-bootstrap spike, and the WASM spike all live in `JS_ENGINE_STRATEGY.md`,
not here.

## Testing Strategy

- **Framework:** Zig 0.16 built-in test runner. No third-party test framework.
  - `zig test` + colocated `test "..."` blocks; `std.testing` asserts (`expect`, `expectEqual`, `expectEqualStrings`, `expectEqualSlices`, `expectError`).
  - **`std.testing.allocator`** is `DebugAllocator`-backed and **fails any test that leaks** — this *is* the mechanism for the arena/no-leak assertions.
  - **`std.testing.io`** (0.16) supplies the `std.Io` required by fixture-file reads and network code.
  - **C interop** via `b.addTranslateC` (0.16 replacement for the deprecated `@cImport`) + `linkSystemLibrary("curl")` + `linkLibC`.
  - **Data-driven tests** = comptime array of case structs iterated in a runtime `for`.
  - **Snapshot/golden** = committed-fixture git-diff (kristoff.it approach) or `oh-snap` for serialized DOM / box-tree / computed-style dumps; framebuffer = PNG export + external perceptual diff (`compare`/`pixelmatch`).
  - **Test doubles** = vtable spy structs recording call order into an (unmanaged, 0.16) `ArrayList`.
  - **Fast loop:** `zig build test --watch -fincremental`.
- **Test types:**
  - **Unit** — url, tokenizer, tree-builder, css-parser, cascade, layout geometry (pure functions; comptime tables; leak-checked).
  - **Integration** — fetch against a local static-file server; full parse→cascade→layout over WPT-subset fixtures; ordered-teardown + microtask-pump call-sequence via spy `ScriptEngine`.
  - **E2E / snapshot** — 50-page corpus → framebuffer → perceptual diff (the 90% gate); URL-in → scrollable-styled-page-out → link-navigate slice.
- **0.16 gotchas baked into every cycle:** `@cImport`→`addTranslateC`; `GeneralPurposeAllocator`→`DebugAllocator`; `ArrayList` unmanaged (pass allocator to `append`); `b.addTest({.root_module=b.createModule(...)})`+`addRunArtifact`; `std.Io`/`std.testing.io`; never `getStdOut()` inside a test (use `std.debug.print`).

# §C — Canonical Contracts (authoritative; pin before any cycle)

> **Why this section exists.** The PlanReview flagged that types, vtable signatures, and
> error-return discipline were described loosely in prose, so the Red tests could not be
> written/compiled and independent cycles risked diverging signatures. This section is the
> **single source of truth** for every shared type and signature. Cycles reference it; they do
> not re-define it. Lock these before coding.

## C.0 — Error-return discipline (global rule) *(resolves Interfaces-critical #3, APIs)*

- **Every fallible public function returns `error{...}!T` with an explicit, named error set.** No public function uses bare `anyerror!T`. `anyerror` is permitted only inside `test` bodies.
- **Transport/TLS/timeout failures are Zig errors. HTTP protocol responses (including 4xx/5xx) are NOT errors** — they are carried in `Response.status`. (See C.3.)
- Each named error documents caller behavior inline: `// caller: halt, do not retry` or `// caller: log & continue`.

```zig
pub const NetError = error{
    InvalidUrl,         // caller: halt, do not retry
    DnsFailed,          // caller: log & continue (user may retry)
    ConnectionRefused,  // caller: log & continue
    Timeout,            // caller: log & continue
    CertInvalid,        // caller: halt, do not retry (security)
    TlsError,           // caller: halt
    TransferFailed,     // caller: log & continue
};
pub const ParseError = error{ MalformedDocument };   // tree builder is recovering, rarely fatal
pub const NavError   = NetError || ParseError;        // navigate() surface
pub const StoreError = error{ CrossOriginDenied };    // caller: halt (security)
```

## C.1 — URL types *(resolves ParsedUrl, url.parse return type)*

```zig
pub const ParsedUrl = struct {
    scheme:   []const u8,        // arena-allocated, lowercased
    host:     []const u8,        // arena-allocated, lowercased; IPv6 keeps brackets
    port:     ?u16 = null,       // null = scheme default (normalized away on parse)
    path:     []const u8,        // arena-allocated; "" means "/"
    query:    ?[]const u8 = null,
    fragment: ?[]const u8 = null,
};
pub fn parse(arena: std.mem.Allocator, input: []const u8) NetError!ParsedUrl; // error.InvalidUrl on failure
pub fn resolve(arena: std.mem.Allocator, base: ParsedUrl, ref: []const u8) NetError!ParsedUrl;
pub fn serialize(arena: std.mem.Allocator, u: ParsedUrl) []const u8;
```
- **Default-port normalization** (C.2 table) is applied in `parse`: a URL with an explicit default port yields `port = null`, so round-trip and origin equality are consistent.

## C.2 — Origin + default-port table *(resolves Origin normalization table)*

```zig
pub const Origin = struct { scheme: []const u8, host: []const u8, port: u16 };
pub fn fromUrl(u: ParsedUrl) Origin;            // fills port from the default table when u.port == null
pub fn eql(a: Origin, b: Origin) bool;          // reflexive, symmetric, transitive
```
| Scheme | Default port normalized away |
|---|---|
| `http`  | 80 |
| `https` | 443 |
| `ws`    | 80 |
| `wss`   | 443 |

`store.zig` API: `get(self,*Store, origin, key) StoreError!?[]const u8`, `set(self,*Store, origin, key, val) !void`, `delete(self,*Store, origin, key) void`. Cross-origin `get` returns `error.CrossOriginDenied`; key-not-found returns `null` (not an error).

## C.3 — Fetch / Response + fixtures *(resolves Response ownership, HTTP-vs-error boundary, timeout, TLS server)*

```zig
pub const Response = struct {
    status:       u16,            // HTTP status; 404/500 live HERE, never as a Zig error
    content_type: []const u8,     // arena-allocated copy
    bytes:        []const u8,     // OWNED BY THE PASSED ALLOCATOR (the page arena);
                                  // freed by arena.deinit() — caller does NOT free separately
};
pub const FETCH_TIMEOUT_MS: c_long = 30_000;     // hung server → error.Timeout
pub fn fetch(arena: std.mem.Allocator, io: std.Io, url: ParsedUrl) NetError!Response;
```
- **Ownership (resolves Contracts/DataModels):** `Response.bytes` and `content_type` are allocated **from the page-arena allocator passed in**; they are freed by `arena.deinit()` on navigate. No separate free path; no double-free.
- **HTTP-vs-error boundary (resolves APIs-critical):** transport/TLS/timeout → `NetError`. HTTP responses (incl. 4xx/5xx) → `Response{.status=N}`. 3xx redirects are **followed silently** up to a fixed limit (`MAX_REDIRECTS = 10`) and never surfaced.
- **Test fixtures (resolves Contracts/Promises/APIs):**
  - `tests/fixtures/static_server.zig` — `Server.init(alloc) !Server` binds an ephemeral port, serves `tests/fixtures/www/*` with declared content-types; `Server.deinit()` closes the socket. Every test uses `defer server.deinit()`.
  - `tests/fixtures/tls_server.zig` — same shape, TLS with a **committed pre-generated self-signed cert/key** under `tests/fixtures/tls/`; used only by cycle 1.4. (If a pure-Zig TLS acceptor is unavailable, launch `openssl s_server` as a child process; kill it in `deinit`.)
  - A **TCP-blackhole fixture** (bind, never `accept`) drives the `error.Timeout` Red.

## C.4 — ScriptEngine vtable (the reserved JS seam) *(resolves the load-bearing critical: Interfaces #1, APIs, DataModels, runScript arg, teardown steps 1&5, drainFinalizers synchrony)*

The vtable is fixed **now** so `NoopEngine` and `SpyScriptEngine` share identical function-pointer
types (mismatches compile silently in Zig — see review). **All five teardown steps** from
`JS_ENGINE_STRATEGY.md §2.2` get a reserved no-op hook so v2 fills bodies without reordering or
adding calls.

```zig
pub const ScriptEngine = struct {
    ptr: *anyopaque,
    vtable: *const VTable,

    pub const VTable = struct {
        // teardown sequence — JS_ENGINE_STRATEGY.md §2.2 steps 1..5, all reserved in v1:
        stopScript:      *const fn (*anyopaque) void,            // step 1 (block new tasks)
        severHandles:    *const fn (*anyopaque) void,            // step 2
        drainFinalizers: *const fn (*anyopaque) void,            // step 3 — MUST be synchronous:
                                                                 //   must not return until all pending
                                                                 //   finalizers have run or been cancelled.
        teardownIsolate: *const fn (*anyopaque) void,            // step 5 (after arena.deinit)
        // execution seam:
        runScript:       *const fn (*anyopaque, source: []const u8) NavError!void, // []const u8 ONLY —
                                                                 //   no DOM-node pointer crosses here,
                                                                 //   keeping the seam decoupled from DOM layout.
        pumpMicrotasks:  *const fn (*anyopaque) void,
    };
    // thin forwarders omitted for brevity; one per method.
};
```
- **`runScript` takes `[]const u8` (script source) only** — deliberately NOT a DOM node pointer, so the seam does not couple to the DOM type before/while it is being built (review's load-bearing concern).
- **`drainFinalizers` is contractually synchronous** (doc comment above). `NoopEngine` satisfies it trivially.
- **Teardown order** (used by cycles 1.6, 6.3): `stopScript → severHandles → drainFinalizers → arena.deinit() → teardownIsolate`. One `fn teardown(...)` encodes it; no cycle re-implements it inline.

## C.5 — DOM node concrete type *(resolves DataModels-critical: DOM node + attribute storage + wrapper-slot policy)*

```zig
pub const Attribute = struct { name: []const u8, value: []const u8 };  // arena slices, lowercased name

pub const WrapperRef = struct { index: u32, generation: u32 };          // generational handle
                                                                        // (JS_ENGINE_STRATEGY.md §2.1);
                                                                        // always null via ?WrapperRef in v1.

pub const Node = struct {
    kind: union(enum) {
        element:  Element,
        text:     []const u8,        // arena slice
        comment:  []const u8,
        doctype:  []const u8,        // name
    },
    parent:       ?*Node = null,
    first_child:  ?*Node = null,
    next_sibling: ?*Node = null,
    script_wrapper: ?WrapperRef = null,  // L4 seam — reserved on EVERY node kind; null in v1.
};
pub const Element = struct {
    tag_name:   []const u8,              // arena slice, lowercased
    attributes: []Attribute,             // arena-allocated slice (NOT a HashMap — arena-friendly,
                                         //   linear scan is fine at element attr counts)
};
```
- **Wrapper-slot policy (resolves the "explicit" gap):** the `script_wrapper` slot lives on `Node`, so **element, text, comment, and doctype nodes all carry it**, all null in v1. Cycle 2.6 asserts each kind.
- All nodes are **page-arena allocated**; navigation pointers are `?*Node` into the arena (freed wholesale by `arena.deinit()` — consistent with the arena invariant).

## C.6 — ComputedStyle schema *(resolves DataModels-critical: ComputedStyle)*

v1-supported properties only. Cascade (Phase 4) computes these; layout (Phase 5) reads them.

```zig
pub const Display = enum { block, @"inline", inline_block, none };
pub const TextAlign = enum { left, right, center, justify };
pub const FloatVal = enum { none, left, right };
pub const ClearVal = enum { none, left, right, both };

pub const ComputedStyle = struct {
    display:     Display   = .@"inline",   // UA initial; box gen overrides per tag
    color:       u32       = 0xFF000000,   // ARGB
    background_color: u32  = 0x00000000,   // transparent
    font_size:   f32       = 16.0,
    font_weight: u16       = 400,
    line_height: f32       = 1.2,          // multiplier of font_size
    text_align:  TextAlign = .left,
    // box model (px, f32 — see C.7):
    margin:  [4]f32 = .{0,0,0,0},          // top,right,bottom,left
    padding: [4]f32 = .{0,0,0,0},
    border:  [4]f32 = .{0,0,0,0},
    width:   ?f32   = null,                // null = auto
    height:  ?f32   = null,                // null = auto
    float:   FloatVal = .none,
    clear:   ClearVal = .none,
};
```
- **Inherited set** (cascade-inheritance, cycle 4.2): `color`, `font_size`, `font_weight`, `line_height`, `text_align`. All others use the struct's initial value.

## C.7 — Box geometry + box→DOM reference *(resolves Box numeric type, box→DOM back-reference)*

```zig
pub const Box = struct {
    x: f32, y: f32, width: f32, height: f32,     // all geometry is f32 (software rasterizer)
    content: union(enum) { block: []Box, line: []LineBox, replaced: ImageRef },
    source: ?*const Node,    // READ-ONLY back-reference into the arena DOM; layout never mutates it.
                             // Not a raw escaping pointer: same arena lifetime as the box tree,
                             // both freed by arena.deinit(); honors §2.3-seam-4 (layout reads, never writes).
};
```
- **Numeric type is `f32` everywhere** in layout → golden-dump equality in cycle 5.1 uses `expectApproxEqAbs` with a fixed epsilon, not bit-equality.

## C.8 — Token, Command, CurlHandle, Page *(resolves Token union, Command.open, CurlHandle sigs, Page fields/init/navigate)*

```zig
// HTML tokens (complete set for the state machine):
pub const Token = union(enum) {
    doctype:   []const u8,
    start_tag: struct { name: []const u8, attrs: []Attribute, self_closing: bool },
    end_tag:   []const u8,
    comment:   []const u8,
    character: []const u8,   // text run
    eof,
};

// CLI:
pub const Command = union(enum) { version, open: []const u8, usage };  // .open carries the URL string
pub fn parseArgs(args: []const []const u8) Command;

// libcurl RAII:
pub fn CurlHandle.init() NetError!CurlHandle;   // error.TlsError if curl_easy_init returns null
pub fn CurlHandle.deinit(self: *CurlHandle) void;

// Page (the navigation unit):
pub const Page = struct {
    arena:    std.heap.ArenaAllocator,   // owns ALL document data
    origin:   Origin,
    dom_root: ?*Node = null,
    style_for: ?*std.AutoHashMap(*Node, ComputedStyle) = null, // arena-backed
    box_root: ?*Box = null,
    scroll_y: f32 = 0,
    engine:   ScriptEngine,              // NoopEngine in v1
    pub fn init(gpa: std.mem.Allocator, engine: ScriptEngine) Page;
    pub fn deinit(self: *Page) void;     // runs the C.4 ordered teardown
    pub fn navigate(self: *Page, io: std.Io, url: ParsedUrl) NavError!void; // THE central call site
};
```
- **`navigate(self, io, url)` is the single signature** referenced by cycles 1.5, 1.6, 6.3 — no per-cycle variants.
- **Concurrency contract (resolves single-threaded assumption):** navigation is **synchronous** — `fetch` blocks; **only one navigation may be in-flight at a time**. A future async fetch is a deliberate, visible change, not a silent one. Documented at the `navigate` definition.

## C.9 — Long-lived vs page-arena allocator split *(resolves display_list domain, font-cache allocator, SDL cleanup)*

| Resource | Allocator | Lifetime | Leak-check note |
|---|---|---|---|
| DOM, CSSOM, ComputedStyle, box tree, `Response.bytes`, **display list** | **page arena** | freed by `arena.deinit()` on navigate | display list is **rebuilt from the page arena each frame**; no pointer survives `arena.deinit()` |
| Glyph/font cache, libcurl handle, SDL window/renderer, HTTP conn pool | **process-lifetime** allocator (dedicated, passed at construction — NOT `std.testing.allocator`) | process | Phase 6 tests inject a test-owned long-lived arena for these so the `std.testing.allocator` leak check is not tripped; `Window.deinit()` calls `SDL_DestroyRenderer`/`SDL_DestroyWindow`/`SDL_Quit`, wired via `defer` |

## Phase 1 — Fetch + arena + reserved seams

### Cycle 1.1 — url-parse-absolute

- 🟢 **Green** — minimal split-based parser covering the table; default-port normalization per §C.2.
- 🔵 **Refactor** — extract component scanners; add the round-trip property loop. Stays green.

### Cycle 1.3 — fetch-success
**Given** a local `http` URL served by the test static-file server
